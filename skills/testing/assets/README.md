# Testing assets

Reusable templates for reporting testing evidence.

- [testing-evidence.template.md](testing-evidence.template.md) — human-readable evidence report with source identity, risk, traceability, executions, and remaining risk.
- [testing-handoff.template.json](testing-handoff.template.json) — machine-readable handoff shape for downstream orchestration/integration.

These are templates, not mandatory storage locations. Adapt them to the repository while preserving exact source identity and evidence semantics.
